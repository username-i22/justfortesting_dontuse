# Tetris Battle Sound Effects Guide

You can place your `.mp3` sound files in this folder (`sounds/`).
If any sound file is missing, the game will **automatically use real-time Web Audio synthesizer sounds**, meaning the game is 100% playable right now with full audio feedback!

### Supported Audio Files:
- `bgm.mp3` - Background battle music (loops automatically)
- `move.mp3` - Left / Right piece movement sound
- `rotate.mp3` - Piece rotation sound
- `drop.mp3` - Soft drop down
- `harddrop.mp3` - Instant slam / hard drop
- `hold.mp3` - Storing a piece in the Hold slot
- `clear.mp3` - 1 to 3 lines cleared
- `tetris.mp3` - 4 lines cleared (Tetris!)
- `attack.mp3` - Sending garbage rows to the opponent
- `receive_attack.mp3` - When opponent attacks you
- `ko.mp3` - Board topped out / KO sound
- `win.mp3` - Victory screen fanfare
- `lose.mp3` - Defeat sound
- `countdown.mp3` - Pre-game countdown beeps
- `start.mp3` - Game start buzzer / bell
